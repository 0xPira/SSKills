# Security Policy

This project is intended for authorized security testing, defensive review, and agent-assisted triage.

Do not use this material against systems you do not own or have explicit permission to test. Do not run malformed framing, queue poisoning, cache poisoning, victim simulation, or timing-sensitive probes without written authorization, isolation, and a stop condition.

If you report an issue in this playbook, avoid including live target data, credentials, cookies, private response bodies, or exploit traffic.
